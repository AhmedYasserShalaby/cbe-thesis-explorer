# CBE Thesis Explorer

Static research workstation for the study of Central Bank of Egypt (CBE) communication and Egyptian Banks / Real Estate sector-index forecasts.

[Open the live Explorer](https://ahmedyassershalaby.github.io/cbe-thesis-explorer/) in a browser (no download, account, or installation required).

## Study Downloads (4 Files)

- `Thesis_Ahmed_Yasser.pdf` — Full 68-page thesis report (with follow-up extensions & 21 Nov audit)
- `Thesis_Presentation.pdf` — 8-slide presentation summary
- `Thesis_Data.xlsx` — Master 6-tab dataset workbook (`Events`, `Returns`, `Statements`, `Prices`, `Results`, `Predictions`)
- `Replication_Code.zip` — Clean `thesis_kit` Python package and executed `Thesis.ipynb` (runs directly on `Thesis_Data.xlsx`)

Original CBE press-release PDFs (`Website/documents/`) open inline inside the Statement Reader.

## Interpretation & Publication

The study is retrospective and exploratory. Unverified original release clocks/text vintages, dependent/overlapping samples, and the January 2020 index-definition change limit interpretation. Rate actions are not measured policy surprises, and event timing does not identify a causal wording effect.
