# CBE Thesis Explorer

Static research workstation for the retained study of CBE communication and
Egyptian Banks/Real Estate sector-index forecasts. Open index.html or Website/.
No server-side model training, live feed or application installation is needed.

The Website/ parent layout is intentional: Current files links resolve to the
report, notebook, workbook, presentation and supporting archive in this root.
Chapter4/ supports the current notebook. No original workspace history, private
correspondence or experiment follow-up outputs are included.

The study is retrospective/exploratory. Publication clocks/text vintages,
dependent/overlapping samples, source coverage and the 2020 index boundary limit
interpretation. Rate actions are not measured surprises; event timing does not
identify a causal wording effect. There is no dependable-live-forecast or profit
claim. See Website/README.md and the app's source/definition panels.

Vendor licenses and pinned versions are under Website/vendor/. No blanket
open-source license for the market data or thesis is asserted by this repository.

## Publication

The owner explicitly confirmed permission to publish the full included data and
linked study files publicly for academic review. This does not grant a blanket
