# CBE Thesis Explorer

Open [the Explorer](index.html) in your browser. **Overview** answers the research question,
**Walkthrough** follows one announcement, and **Forecast results** opens
the saved evaluation. Use **Filtered meetings** to apply your own selection.
On phones, open **Settings** in Forecast results to change the evaluation,
scope or measure. **Forecasts by meeting** carries over the selected meeting
and shows when it has no scored forecast in the active selection.

On **Overview**, switch between **Full history** and **Modern indices** to
compare forecast errors on a common scale. **Open this evaluation** takes you
to the selected results. The March 2024 timeline links directly to the CBE
statement and the saved forecasts. On phones, the **6 March 2024 example**
shortcut opens the announcement step. The Walkthrough shows one slide at a time.
Use Previous and Next, the step picker, or the left and right arrow keys.
**Details** opens exact values, methods, and source links for the current slide.

Open **Compare wording** on an announcement to see highlighted changes in
the full text, only changed paragraphs, or two separately labeled readings.
The dated source links open both original PDFs. The sticky comparison controls
jump between change groups without closing either statement.

The top-left **Menu** button toggles the navigation drawer across desktop and
phone layouts, keeping **Search Explorer**, **View link**, and **Study files**
inside the drawer with no fixed top bar. Research views start directly with
their controls or content. **Definitions & files** presents the main downloads
as cards with file types and sizes and keeps the raw CSV list under **Source
datasets**. Dropdowns use centered custom arrows, and **Daily market records**
includes rows-per-page choices and a date jump. Use a panel's info button to
read definitions and caveats.
Filter presets highlight the selected date range. Applying a filter updates
the toolbar before redrawing charts. Applying the same selection closes the
dialog without redrawing. The Overview headline uses medium-weight Inter.
The interface uses layered charcoal gradients and graphite controls, with color
reserved for chart marks and legends.

Use **Search Explorer** or `Ctrl+K` / `⌘K` to find a study view, statement, or
bundled file. Use **Data** inside a chart to sort its source rows or export
a CSV. The **View link** dialog copies the active section and filters and
imports or downloads portable settings. Its offline fragment can be appended
to the address of another copy of this Explorer build.

See the [design notes](DESIGN.md) for the interface and its references.
